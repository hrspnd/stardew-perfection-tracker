# Stardew Valley Perfection Tracker

## The Idea
A Stardew Valley Perfection Checklist web application built with React. The website will help players track their progress toward achieving 100% Perfection by organizing objectives into categories and saving their completion progress.

## Why
Many existing checklists are static or difficult to keep track of over time. This project will provide an organized and user-friendly way for players to monitor their progress.

## Scope
- Export featurue to save checklist progress.
- Users can continue where they left off after importing.
- Perfection checklist organized into categories (Shipping, Fish, Museum, Cooking, Crafting, Friendship, etc.).
- Checkboxes to mark completed items.
- Progress bars for each category and overall completion.

### Deliberately Out of Scope
- User registration and login.
- Importing Stardew Valley save files.
- Multiplayer features.
- Search or filter functionality for checklist items
- Community features such as sharing progress.
- Integration with mods or external APIs.
